# Conceito visual premium — Gênesis Atividades

Este diretório preserva o protótipo aprovado da nova experiência visual.

## Estrutura proposta

- Página institucional em scrollytelling com os capítulos Crie, Adapte, Edite e Entregue.
- Rota separada de criação, para o professor sair da apresentação e entrar no workspace.
- Logo oficial do Colégio Gênesis Life.
- Identidade minimalista baseada em magenta, amarelo e superfícies claras.
- Workspace com configurações à esquerda, folha A4 no centro e propriedades à direita.

## Importante

Este conceito foi mantido isolado para não alterar a lógica atual do aplicativo. A integração no App.jsx deve preservar autenticação, Supabase, APIs, geradores Normal e PRO, histórico e exportação Word.
